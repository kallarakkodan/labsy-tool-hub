# 18 — lib/auth.ts: scrypt verification, sealed session cookie, gen:hash

Status: ready-for-agent
Phase: P2
Blocked by: 03
Spec: PRD §8.1, CONTEXT §4, CONTEXT §7.4 (isAdmin), CONTEXT §8 step 6

## Why

`isAdmin` feeds `toolVisibilityWhere` on every read path. Until this lands, the
visibility system is only half-tested.

## Scope

One module, `src/lib/auth.ts`, per
[ADR-0001](../../../docs/adr/0001-session-format-jose-jwe.md) and PRD §10. The
Next 16 route guard (`proxy.ts`) runs on the **Node.js** runtime, so there is no
Edge boundary to split around:

- `verifyPassword(plain)` — scrypt against `ADMIN_PASSWORD_HASH`, compared with
  `crypto.timingSafeEqual`
- `seal()` / `unseal()` — compact JWE via `jose`, `alg: "dir"`, `enc: "A256GCM"`,
  key derived from `AUTH_SECRET` by HKDF-SHA256, `SESSION_TTL_HOURS` expiry
- `getSession()` — returns the session or `null`
- `isAdmin()` — `getSession() !== null`
- Cookie: `labsy_session`, HttpOnly, `SameSite=Lax`, `Secure` from
  `COOKIE_SECURE`, `Path=/`.
- `scripts/gen-hash.ts` + `pnpm gen:hash` — prompts for a password (no echo),
  prints the `ADMIN_PASSWORD_HASH` line to paste into the env file.
- Replace the `isAdmin` stub in issue 11's routes with the real call.

## Done when

- [ ] Tests: correct password verifies; wrong password fails; a hash generated by
      `gen:hash` round-trips
- [ ] Test: a cookie with a tampered payload or signature is rejected
- [ ] Test: an expired session is rejected
- [ ] Test: an admin session now sees drafts and internal tools through
      `/api/tools` (the case stubbed in issue 11)

## Watch out

- Timing-safe comparison on the **derived key**, not on the password string.
- `getSession()` must never derive admin-ness from a query param, header, or
  anything else client-controlled (CONTEXT §7.4).
- Sessions are stateless — no revocation. Logout clears the cookie; rotating
  `AUTH_SECRET` is the break-glass. Recorded and accepted in ADR-0001.
- `cookies()` is async in Next 16 — `await cookies()` in both seal and unseal.
- Store the scrypt parameters (N, r, p, salt) in the hash string so they can be
  raised later without invalidating the format.
